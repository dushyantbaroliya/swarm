Every card below is a separate replica with its own copy of the board. They only talk through the simulated network in the side panel. Draw on any of them, then add latency, drop packets, or slice the network in two. They will disagree for a while. They will always agree in the end.

    How it works

    01

    Every edit is an op with a clock

    Moving a shape doesn't send the board. It sends one small op: set ana:3.x = 240, stamped with a Lamport clock and the author's id. That stamp gives every edit ever made a single order that all peers agree on, without asking anyone.

    02

    Last writer wins, per field

    Each field of each shape is its own register, and the higher stamp wins. So if you move a box while I recolour it, both edits survive. Only true collisions (two people moving the same box at once) need a winner, and every replica picks the same one. That's the amber flash.

    03

    Text is a sequence, not a value

    Sticky notes use RGA, a sequence CRDT. Each character remembers which character it was typed after. Two people typing at the same spot get their words placed side by side, never interleaved letter by letter, in the same order on every replica.

    04

    Gossip heals partitions

    Ops are pushed immediately, but pushes get lost. So peers also gossip version vectors (“I have ana up to 41, bao up to 17”). Anyone holding what you lack sends it, even ops they didn't write. Cut a link and the ops route around it.

    05

    Deletes are just another field

    There is no delete op. Deleting sets deleted: true, and undo sets it back. That keeps the whole model to three ops and makes "move vs delete" races resolve like any other write.

    06

    Proven by 10,000+ random histories

    Property-based tests generate random edit histories across four peers, deliver every op in a random order with duplicates, and require byte-identical state at the end. Another suite runs the full network with loss, jitter and partitions, and requires convergence after it heals.

    Built from scratch by Dushyant Baroliya. No CRDT libraries, no server, no framework.
